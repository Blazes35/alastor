# Alastor - Discord Bot

Alastor est un bot Discord conçu pour répondre aux attentes d'un serveur entre amis. Développé avec la bibliothèque [discord.js](https://discord.js.org/), il offre des fonctionnalités de modération, d'animation et d'utilitaires, dont la traduction via l'API DeepL.

## Description

Alastor est un bot Discord conçu pour enrichir l'expérience des serveurs entre amis. Il combine plusieurs fonctionnalités clés pour :
- **Modération :** Gérer et surveiller le serveur.
- **Utilitaires :** Proposer des commandes amusantes et pratiques.
- **Traduction :** Traduire des textes en utilisant l'API DeepL.

## Commandes

### Modération
- **reaction-role** : Crée un message avec des rôles de réaction.
- **server** : Fournit des informations sur le serveur.
- **timeout** : Met un utilisateur en timeout.
- **user** : Fournit des informations sur un utilisateur.

### Utilitaires
- **bonk** : Envoie un sticker "bonk" à un utilisateur.
- **full-reload** : Recharge toutes les commandes.
- **info-command** : Fournit des informations sur une commande spécifique.
- **logChannel** : Change le canal de log.
- **ping** : Répond avec "Pong!".
- **reload** : Recharge une commande spécifique.

### Traduction
- **translate** : Traduit un texte en utilisant l'API DeepL.
- **quota** : Affiche l'utilisation actuelle des caractères de l'API DeepL.
- **source_list** : Affiche la liste des langues sources disponibles.
- **target_list** : Affiche la liste des langues cibles disponibles.
